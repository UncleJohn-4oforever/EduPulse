# 页面阅读体验调整

- 常规正文、表格及输入控件以16px为主，辅助文字最低14px，班名18–20px。取消手机上将表格再次缩小的规则。
- 加深浅灰绿色说明、账号、表头、表单标签和状态文字；强化输入框边界与键盘焦点提示。
- 按钮高度至少44px，表格行与表单间距同步扩大。较窄屏幕的统计卡片分成两列，手机表单改为单列，搜索框独占一行。宽表格仍可在表格区域横向滚动。
- 学生时间输入分行显示，保持可操作尺寸；侧栏在较矮电脑屏幕上可滚动。

验证：TypeScript检查和生产构建通过；Chrome教师端/主管端在360、390、768、1024、1280、1440px宽度下无整页横向溢出，可见文字不低于14px，表格和输入框16px。原教师默认值与学生冲突浏览器回归通过。使用独立虚构测试数据，没有修改业务数据库。

脚本：`scripts/browser-readability.cjs`。页面截图：`docs/screenshots/readability/`。
