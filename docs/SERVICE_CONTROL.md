# 手动关闭与重启

- `结束后台.bat`：关闭本项目当前端口上的服务。已保存账号和数据保留，尚未提交的编辑应先保存；关闭可能中断正在执行的请求，SQLite会回滚未提交事务。
- `重启.bat`：调用关闭脚本，成功后调用`开始.bat`。若没有正在运行的服务，直接启动；关闭失败或端口被其他程序占用时取消启动。
- `开始.bat`：已改为使用本目录解释器和`run.py`的绝对路径，便于准确识别项目进程。后台独立运行，启动就绪后自动打开登录入口页；关闭启动窗口或网页都不会结束后台。重复启动会复用同一服务并重新识别网络地址。

脚本优先读取当前环境的`EDUPULSE_PORT`，其次读取项目`.env`，默认8000。关闭前核对运行命令、项目解释器/父进程或绝对入口路径，并在终止前复查进程创建时间，避免PID复用。不会批量关闭所有Python程序。只有进程身份和端口匹配时才关闭；当前实现使用Windows进程终止，用于故障时手动恢复。

若提示访问被拒绝，请右键BAT，选择“以管理员身份运行”。脚本不包含账号密码，不修改数据库内容，不自动重置用户或重新初始化账号。必须使用运行系统的同一Windows用户，以保持默认数据目录一致。

仅检查而不关闭：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\stop-service.ps1 -CheckOnly
```

验证：PowerShell语法检查通过；正式8000端口仅做只读身份核验；隔离8069端口实际关闭成功，重复关闭成功，`重启.bat`从停止状态启动后健康检查正常。另在8070端口启动临时Python HTTP服务，脚本拒绝关闭且该服务仍存活。测试不关闭正式服务。

登录入口由 `scripts/launch.py` 在本机 `.logs/登录入口.html` 生成，不包含账号密码；显示主管本机入口、教师局域网入口，并提供打开及复制按钮。电脑多网卡时显示多个地址；仅绑定本机或未取得网络地址时明确提示。端口和 HTTPS 读取当前配置，后台健康检查通过后才打开入口。
