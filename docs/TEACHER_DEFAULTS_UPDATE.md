# 教师录入体验与学生撞档提醒

- 新建班级未手动命名时，根据第一位学生的第一个档位自动命名，如“周六一档”。保存前调整该档位会同步更新自动名称；手动输入优先，清空后恢复自动命名。已保存的名称保留，空班仍可手动命名。
- 添加第二位及后续学生时，复制第一位学生的星期、档位及具体时间。复制后可独立修改，允许特殊情况下添加多个档位。
- 新增班级沿用当前教师上次选择或保存的科目。在同一浏览器按账号分别记忆，刷新或重新登录可沿用；科目已删除时回退到有效科目。浏览器禁用存储时仅在当前页面会话记忆。
- 学生以稳定编号识别，在不同班级之间检查本人时段。双方时间完整时按实际时间重叠判断；缺少具体时间时，同星期同档位提示可能撞档；相邻时间不冲突。不同教师相同班名不构成冲突。
- 冲突允许保存。教师看到涉及本人班级的提醒；主管在“教师负荷”相关教师行查看，并在“学生列表”看到“学生排课冲突”标记，展开查看细节。提醒不包含其他班级的学生名单或评价。
- 提醒基于已保存数据，通过现有实时通知和30秒轮询刷新。历史快照、统计口径和数据库结构保持原样。

验证：后端59项测试通过（含新增7个学生冲突用例）；TypeScript检查及生产构建通过。Chrome浏览器验证通过，覆盖三项录入功能、教师及主管学生冲突提醒、评价隔离和390px手机布局。浏览器验证脚本为 `scripts/browser-class-defaults.cjs`，必须使用隔离测试数据库。

本机旧 `.venv` 引用的 Python 路径已失效。本次在独立 `.test-venv` 安装随包离线依赖完成验证，没有修改业务数据库。正式启动前需确保原运行环境的 Python 可用。

## 班级年级跟随学生

班级新建及编辑表单取消独立的“年级”选择。班级标题、当前报表与导出的班级年级直接取自班内学生档案；不同年级去重后并列显示，空班暂不指定年级。学生添加弹窗保留“新建学生年级”，默认沿用本班第一位学生的年级。班名仍按“周六一档”自动生成，手动名称优先。

后端不再要求提交班级年级，兼容旧客户端提交该字段但不以其覆盖学生年级。数据库结构和历史快照保持原样，已有班级也直接按学生档案显示当前年级。验证：后端61项测试、TypeScript检查、生产构建及教师端浏览器回归通过。
