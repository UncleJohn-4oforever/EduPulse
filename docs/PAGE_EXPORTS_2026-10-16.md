# 按当前页面导出

概览取消XLSX及PNG导出按钮。教师满班率、教师负荷、学生列表分别携带view参数导出各自页面内容，沿用当前全部筛选、实时/历史范围，以及页面排序。导出包含筛选后的全部记录，不受每页条数和当前页码限制。

- 满班率XLSX：教师满班率明细、三种小班满班率/班容汇总、统计说明。
- 负荷XLSX：各班型周课次、总课次、固定基准15、课次/15、可超过100%的负荷率、班级数与核对状态。
- 学生XLSX：学生列表（含未关联班级的学生）、科目/教师/班级/评价/档位明细、统计说明。
- PNG：当前页面对应的汇总表，按内容换行并计算行高。

百分比和班容在XLSX中保留数值类型及两位小数格式；姓名和评价沿用公式注入防护。历史快照只读，沿用其原始统计数据。广播页的历史综合导出及不指定view的旧接口保持原有兼容行为。

验证：66项后端测试通过；浏览器验证三个页面实际XLSX/PNG下载、文件名称、全部记录、排序、筛选与历史参数，并确认概览无导出入口。人工查看PNG示例，核对中文、换行和列间距。
