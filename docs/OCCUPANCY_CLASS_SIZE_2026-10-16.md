# 主管端满班率与班容展示

主管概览、教师满班率和教师负荷页的满班率汇总改为更大的三栏区域：一对三、一对六、综合平均。百分比旁显示平均班容，教师满班率明细及概览席位分布也补充班容。

计算沿用当前口径：各班型满班率为总席位除以总容量；综合为一对三和一对六合计席位除以合计容量，不平均两个百分比，不含一对一。班容为相同范围内总席位除以班级数，空班计入分母，保留两位小数。没有对应班型显示“—”。同一学生在不同班级分别占用席位。

汇总使用筛选后完整教师数据，列表分页不影响汇总。历史页面从原快照中的席位、容量、班数派生班容，不查询当前班级重新计算；快照存储不修改。数据库、后端接口及本版PNG/XLSX导出格式未改动。

布局：三栏满班率为主区，原教师/班级、周课次和学生档案卡片置于其下；电脑明细百分比旁显示班容，较窄电脑自动换行，手机三栏纵向排列。延续清晰字号和配色。

验证：TypeScript与生产构建通过。`scripts/test-occupancy-summary.cjs`覆盖按容量加权、不同教师汇总、班容、空班、缺少班型和排除一对一。`scripts/browser-occupancy-summary.cjs`通过示例5/12、12/54、17/66及对应1.25、1.33、1.31人/班检查，并覆盖校区/科目筛选、空班分母、历史快照不变、360–1440px六种屏幕宽度无整页溢出。
