# 教学主管与教师使用说明

## 主管：第一次使用

1. 用主机初始化时创建的账号登录，进入「教师账号与密码」。先到设置补充校区、科目或年级。
2. 点击新增教师，填姓名和校区；多人可批量导入，每行一个姓名。同名教师账号也不同。
3. 对未分配密码的教师点「生成初始密码」，或选择多人批量生成。弹窗仅短暂显示，复制单人的姓名/账号/密码私下发放，也可下载本批CSV。关闭后无法再次看旧密码。
4. 丢失密码请重新生成。重置会立即注销老师的旧登录，不影响其他教师；停用教师后同样无法继续登录和读写。
5. 不要把凭据发到公共群，发放完成后妥善删除集中下载的CSV。

## 教师：维护我的班级

1. 使用收到的唯一登录账号和密码登录。「我的班级」只显示自己的班级，页头显示自己的姓名。
2. 新增班级，选择科目、年级、一对一/三/六，填写显示名称。老师字段自动绑定本人。
3. 上课档位现在放在各学生卡片内。每位学生至少一条，选择星期与第1至第6档，可添加多条；开始结束时间可留空，若填写则同时填写。多名学生在同班同星期同档位共同上课，教师只计1次周课次。
4. 点添加学生，先搜索姓名或编号，查看年级及稳定编号，确认是同一人才加入。一个学生报多个科目时复用同一档案。
5. 找不到可以新建。同名学生不自动合并，系统会提醒确认，主管可之后人工合并真正重复档案。
6. 每位学生有独立小卡片：A/B/C单选和可选1000字备注。达到班型容量后禁止继续添加；缩小容量前先移除多余学生。
7. 点击保存班级更改，学生的档位和评价一并保存。成功后数据持久化，刷新仍会预填。保存失败时读错误并修正，不要直接离开。
8. 移除学生或删除班级会弹出明确确认。移除的是本班关联、学生档位及评价，学生档案仍在；已冻结的历史报表不会改变。
9. 同一个班在两台设备同时编辑时，较晚保存的旧版本会收到冲突提示。先复制未保存内容，再刷新核对，避免覆盖别人更改。

## 核对广播

主管进入采集广播，发起任务，填写标题、开始/截止时间和目标校区。可以只勾选某几位教师；不勾选表示所选校区全部启用教师。创建后目标人数固定，之后新教师不会改变本轮分母。

在线教师收到醒目任务提示；关闭网页的教师在截止前重新登录也能看到。主管任务时间按北京时间输入和显示。

教师核对已有班级，按需修改并保存，最后点「确认本轮数据」。数据完全没有变化时也可以确认。未保存的修改会阻止确认，**保存本身不算本轮确认**。

主管可实时看已确认/目标人数和每人的确认时间。截止、全部确认或主管手动结束会冻结快照。结束后不能继续确认；需要新的核对就新建下一轮。未确认的数据仍在，标注“未经本轮确认”，不会替换为0。

## 主管：看板和导出

- 教师满班率：显示人数/容量、班数、百分比及空位。一对一单独统计，不进入小班满班率；没有对应班型显示 —。
- 教师周课量：汇总每位学生的周档位，在班内按星期+档位去重。六人班的所有学生都选周三第3档、周六第3档，教师计2次，不计12次；若有学生额外选周四第6档，全班计3次。展开教师可查看班级和时段。
- 学生列表：学生编号稳定；同一学生数学两个班仍只计1科，数学加英语计2科。展开按科目/老师/班级看对应评价和更新时间。
- 通过校区、科目、教师/学生姓名等筛选；点下一页查看更多。小屏幕表格可在表格区域滑动，填写页面为响应式卡片。
- 当前看板可导出PNG（不含全部学生文字评价）；明细导出XLSX，包含教师、负荷、学生评价、班级与本轮确认清单。
- 查看过去一轮：在统计范围选择已冻结任务，或在采集广播点击历史PNG/XLSX。之后修改当前数据不会覆盖历史结果。

## 共用电脑

使用结束务必点侧栏「退出登录」。会话默认8小时过期。忘记密码联系主管，不需要重新注册。局域网HTTP环境不支持一键复制时，可手动选中弹窗凭据或下载CSV。

## 主机运维

主机窗口保持运行，其他设备用同一局域网主机地址访问。关闭窗口或主机休眠后其他设备无法连接；重新启动后数据仍保留。

定期运行 backup.bat，备份保存在数据目录backups。恢复前先停止服务；具体方法参阅README。账号、评价、明细导出和备份都是内部敏感资料，避免共享给未授权人员。

## 主管删除教师和类别

教师账号页每行的「删除」会明确提示该教师当前班级数量。确认后，其当前班级、学生报名关联、档位与评价被删除，登录立即失效；学生基本档案、其他老师的记录及已冻结的历史报表保留。删除不能直接撤销；如需恢复业务记录，应使用事先的数据库备份。

设置页选择校区、科目或年级，点击名称旁的X删除。它从可选类别中移除，已有班级/学生的名称不会被抹掉。旧班级可继续沿用其原类别，新记录必须使用有效类别。重新新增相同类型、相同名称会恢复原类别。所属校区被删除时，请先把教师调到有效校区再新建班级/学生。

## 从旧版升级后的档位

旧班级的时段自动复制到该班每位学生卡片。明确的一档/三档/第6档等会映射为六档下拉；其他旧文字名称原样保留并提示您核对选择，系统不会擅自猜测。先选好第1至第6档，再保存班级。历史快照及其旧统计口径保持不变。
