# 教师工作区与连续录入

## 课程导航

“我的班级”改为“班级总览”，默认显示全部班级。左侧仅列出有课的星期，按周一至周日排序，例如“周三 共三档”；点击筛选当天的班级。同班同星期同档位的多位学生只计一档，不同班分别计数，沿用原有周课次口径。标签基于已保存的数据更新。

在某一天点击新增班级，第一位学生的星期默认跟随当前日期标签。班级总览中首次添加学生仍默认周三第三档。后续学生继承第一位学生的档位和时间，可独立修改。切换标签遇到未保存内容时要求明确选择是否放弃。

## 班级录入

- 首行是任课老师、科目和班型，不再填写独立班级年级。
- 点击“添加学生”直接增加行：姓名、年级、星期、档位、开始时间、结束时间；下方保留添加按钮，达到班型容量后禁用。
- 姓名输入后在本行下方搜索已有档案，显示姓名、年级、编号，确认身份后复用。已有学生的姓名和年级锁定；需换人时点击“重新选择”。若确为同名的不同学生，保存时确认新建独立档案。
- 尚未建立档案的学生在保存班级时创建；班级保存失败时保留已创建的学生编号，重试不会重复创建这些档案。
- 程度标签和文字评价保留在每行的展开区。已移除“添加额外档位”入口；已有多个档位的数据仍保留，可查看、编辑或移除已有额外档位。
- 班名位于学生区之后，默认生成“周六一档”等名称，手动输入优先。科目继续按教师账号在当前浏览器记忆。

已保存班级默认折叠，保存和取消编辑后也自动折叠；摘要显示班名、任课老师、科目、班型、人数，以及每位学生的姓名、年级、星期、档位和时间。点击标题或“展开编辑”进行修改。

## 页面精简

教师端取消重复的校区路径顶栏、教学管理标记、教师姓名问候和说明性文案，没有广播时不显示空提示。有广播时显示紧凑的任务和确认入口；未保存内容仍阻止确认。排课冲突以可展开的醒目提示保留。电脑使用行式布局，较窄电脑和手机合理换行，继续保留16px输入文字及较高对比度。

## 验证

后端61项测试、TypeScript检查及生产构建通过。`scripts/browser-teacher-workspace.cjs` 验证行内新建/复用学生、档位继承和独立修改、评价保存、自动及手动班名、科目沿用、折叠摘要、星期档数与筛选、未保存切换保护、手机导航、广播确认和学生冲突提醒。360–1440px六种宽度检查无整页横向溢出。

`scripts/browser-class-defaults.cjs` 转调新的工作区验证脚本；`scripts/browser-readability.cjs` 已适配折叠班级。历史发布版本的其他浏览器脚本保留，教师端旧卡片/弹窗的定位不再适用于此布局。

验证均使用独立临时数据库和虚构人员，业务数据库未修改。数据库结构、后端接口和历史快照格式没有变化。截图位于 `docs/screenshots/workspace/`。
