# EduPulse 1.2.2 教学数据工作台

可在校区局域网运行的真实教学数据采集系统。前端 React + TypeScript + Vite + Tailwind CSS，后端 FastAPI + SQLAlchemy + SQLite，WebSocket 实时广播。所有统计由后端计算，数据不依赖云服务。

项目包含完整源码、已构建前端、Windows 启动脚本、Python 3.12 x64 的离线依赖、自动测试和中文使用说明。**没有公开默认管理员密码，没有预置教师、学生或业务数据库。** GitHub仓库保存程序代码；本机数据库、备份、配置、日志、导出文件和验收截图不会上传。

## Windows 快速开始

1. 校区主机安装 **Python 3.12 64位**，安装时保留 Python Launcher（`py`）。最新修复及撞档提示见 [1.2.2说明](docs/RELEASE_1.2.2.md)。本包不包含 Python 解释器；前端已经构建，使用时不需要 Node.js。已在使用旧版的主机先停止服务并备份，参照docs/RELEASE_1.2.md升级，不用重建账号。
2. 解压到可写目录，例如 `D:\EduPulse`，不要直接在压缩包内运行脚本。
3. 双击 `首次运行.bat`：自动创建 `.venv`，从随包 wheels 离线安装依赖，创建数据库，然后交互式创建教学主管。输入至少14位、含字母和数字的强密码，输入时不回显。没有写死的默认密码。
4. 双击 `开始.bat`，后台启动后会自动打开“登录入口”网页。点击“教学主管登录”进入系统；启动窗口和入口页都可以关闭，后台继续运行。
5. 在登录入口页点击教师网址旁的“复制网址”，粘贴发给老师即可；无需查询 IP。其他设备需连接校区同一网络。若有多个网络地址，依次尝试。网络地址变化后，再次双击“开始”会更新网址，不会重复启动后台。在 Windows 防火墙仅允许专用网络的配置端口入站。
6. 主管在「教师账号与密码」增加教师、生成密码、私下逐人分发；教师登录后进入「我的班级」。

默认数据目录为 `%USERPROFILE%\EduPulseData`（与代码分开）。必须让主机使用固定 Windows 用户运行，避免切换用户后打开不同数据目录。升级时不要覆盖数据目录。

手动关闭服务：双击 `结束后台.bat`；关闭后重新启动可双击 `开始.bat`，或直接双击 `重启.bat` 完成关闭并重启。关闭可能中断正在提交的请求，请先保存编辑。脚本读取 `.env` 中的端口，核对项目进程后才关闭，不删除账号或数据；服务未运行时可直接重启。若提示权限不足，右键选择“以管理员身份运行”。端口被其他程序占用时拒绝关闭，并取消重启。

修改端口、数据目录、HTTPS 或字体：复制 `.env.example` 为 `.env`，按注释配置。修改后重启服务；登录入口会按当前端口和网络地址自动生成网址。建议给主机保留固定局域网 IP。

如果主管已初始化，重复执行“首次运行”的初始化步骤会提示账号已存在，不会重置密码；直接双击“开始”即可。管理员初始化失败可重新运行 `.venv\Scripts\python.exe run.py init-admin`，也可使用 `--username` 和 `--name` 指定管理员账号与姓名。

## 校区名称

各校区独立运行本系统。教学主管进入「设置 → 校区名称」，填写名称并点击「保存校区名称」，工作台顶部即显示「校区名称 / 当前页面」。名称最多40个字符，保存在本机数据库中，刷新、重新登录或重启后仍保留，也随数据库一起备份与恢复。未设置时沿用原顶部显示。

## 界面风格

教学主管在「设置 → 界面风格」可切换「魔兽 · 史诗」和「经典 · 清爽」，立即生效。默认使用深色史诗风；选择保存在当前浏览器，刷新或重新登录后保留。各设备可独立选择，教师端与登录页面沿用原风格。主题只改变显示，满班率、科目比等完整汇总与报表导出保持原有数据口径。

## 已实现功能

- 主管单个或批量录入教师名单（每行一个姓名，选定所属校区），自动生成唯一账号；停用、重新启用、修改姓名/校区、确认删除教师及其当前班级。
- 密码学随机18位密码、Argon2id 哈希、当次临时展示、单个复制与本批 CSV 导出。关闭、刷新或5分钟后清除展示；遗失只能重置。重置/停用立即使旧会话失效。
- 教师本人班级隔离；科目、年级、一对一/三/六、每位学生的星期/第1至第6档/选填时间、学生搜索/新建/移除、A/B/C和独立文字评价。容量在后端验证，保存后刷新保留。删除明确确认，编辑有版本冲突保护。
- 满班率容量加权（不含一对一）、周课次按学生档位在同班、同星期、同档位去重、学生跨科去重。校区/学科/姓名/年级/教师筛选，教师排序，列表分页，展开班级及评价。
- 指定校区或教师广播、固定目标名单、在线 WebSocket 通知、登录与30秒轮询补查、无变化确认、实时进度、截止限制。
- 全部确认、截止或主管手动结束时冻结本轮统计和必要明细；未确认教师明确标注。历史快照 PNG/XLSX 导出不受之后编辑影响。
- 中文 PNG 看板；XLSX 含教师满班率、教师周课量、学生科目教师评价、班级明细、填报完成清单、统计说明六个工作表。Excel 百分比和数字保留正确类型；防止用户文本被当成公式执行。
- 校区/科目/年级字典新增与删除（保留已有引用和名称）、人工学生合并（同班评价冲突要求人工处理）、最近200条操作审计。
- 新校区首次初始化默认提供数学、英语、语文、物理、化学、生物、道法、历史；年级为初一至初三、高一至高三、一年级至六年级。各校区可以自行增删，重启或升级不会重置已有字典；初始校区名称为“主校区”。
- SQLite 外键/WAL、在线兼容备份、停止服务后的恢复工具。

## 设计假设与明确边界

1. 一台主机、一个后端进程（`workers=1`）；SQLite 适用于校区轻量并发。每个班仅一位主讲教师。
2. 登录必须使用唯一账号，姓名仅用于显示。账号不会由同名老师姓名推导；同名学生、同名教师均不会自动合并。
3. 教师可跨校区搜索最少学生身份信息（姓名/年级/编号）以复用稳定学生ID，不能读取其他教师的评价或全局报科统计。新建学生使用自己的校区。
4. 新建班级允许空学生名单，空班周课次为0；每位学生在本班必须有至少一个周档位。空班满班率为0%。没有对应班型显示 `—`，XLSX 显示 `N/A`。
5. 一对一单独显示班数和周课次；周课量按各班学生档位的并集计算：同班同星期同档位计1次，不同班分别计次；它是固定排课次数，不是实际授课数、分钟数或饱和度。
6. 教师点击保存与本轮确认是独立操作，未保存编辑会阻止确认。已确认教师可在本轮结束前再次确认；最后一位确认会自动结束本轮。数据编辑不会自动撤销确认，若又修改了数据应在有效轮次内再次核对确认。结束后新建下一轮。
7. 快照在**本轮结束时**记录全部校区当时的真实汇总和明细，再标注固定目标名单是否确认。创建任务时不会冻结数据。截止后台每15秒检查；任意写入也会先冻结已过期任务，防止截止后编辑漂移。服务停止时无编辑，重启或首次访问时补冻结。需要更早保留统计时可主管手动结束。时间统一 UTC 存储，前端、PNG、Excel按 Asia/Shanghai 显示。
8. 历史快照包含当时显示姓名、科目、班级、评价及目标名单；当前字典只是筛选选项。历史快照本身不会随改名/合并/删除变化。
9. 删除班级明确删除当前学生关联、学生档位和该班评价。删除教师需确认删除其全部当前班级及相关评价；保留学生基本档案、其他教师的关联、审计和冻结历史。删除类别后不再供新记录选择，已有记录仍可沿用原类别；新增同名类别可恢复原ID。不会用「班级状态」或「学生状态」扩张业务范围。
10. 教师所属校区变更同时移动其当前班级并递增班级版本；不改变历史快照。第一版没有管理员在界面替老师编辑/代填班级功能。
11. 批量名单以姓名逐行粘贴导入，凭据输出为CSV（满足规格中的CSV/XLSX任选其一），不读取外部名册文件。复制按钮需要浏览器安全上下文；HTTP局域网浏览器不支持剪贴板时可手动选中复制或下载CSV。
12. 不包含收费、课消、自动排课、考勤、微信推送、AI评价、短信邮箱找回、自助改密或公网部署。不会自动产生业务假数据。

## 安全与网络

- 会话令牌使用高熵随机值，数据库仅存令牌哈希；HttpOnly + SameSite=Strict Cookie，8小时过期。写请求校验CSRF令牌及Origin，默认同源，无跨域放行。
- HTTP/WS都服务端鉴权，所有教师班级接口用会话身份判断归属，拒绝请求体额外字段，不信任传入 teacher_id。所有管理员报表及导出仅主管可用。
- 登录按来源IP限制，5分钟内10次失败后限速；错误统一，不透露账号存在性。共享出口下此限制可能同时影响多人；单进程重启会清空内存限速计数。
- 敏感HTTP响应 `Cache-Control: no-store`；退出后清空前端用户数据，页面恢复/轮询检查会话。密码重置递增 session_version，WS立即或心跳检查失效会话。
- 登录、重置、停用、班级修改/删除、广播确认、合并与导出写审计，不记录明文密码或评价文本。凭据CSV在主管自己的下载目录，应私下发送，发放后删除，不应长期集中保存。
- 默认 HTTP 适用于受控可信局域网，传输不是加密的；跨不可信网络或需要保护传输时使用可信局域网HTTPS证书，并设置 `EDUPULSE_SECURE_COOKIE=true`、`EDUPULSE_SSL_CERT`、`EDUPULSE_SSL_KEY`。证书需被各客户端信任；不接公网。后端默认不信任代理头。
- 主机应限制Windows用户和数据目录的访问权限；SQLite包含敏感评价及快照，备份同样需要妥善保管。

## 备份与恢复

双击 `backup.bat` 可在服务运行时用 SQLite Backup API 创建一致备份，输出到数据目录的 `backups`，并执行完整性检查。不要直接复制写入中的数据库文件。

需要定期备份时，在 Windows 任务计划程序创建每日任务：以运行本系统的同一个 Windows 用户执行 `D:\EduPulse\backup.bat`。程序未运行也可备份。将重要备份另存至受控移动硬盘；定期实际演练恢复。

恢复：先 `Ctrl+C` 停止主机服务，然后在终端执行：

```bat
restore.bat "D:\backup\edupulse-20261014-180000.sqlite3"
```

输入 RESTORE 明确确认。脚本先备份当前数据，再检查并恢复指定备份。恢复成功后重新 start；历史快照、教师账号和评价随数据库恢复，恢复时会清空所有会话并递增账号会话版本，所有人需重新登录。密码本身仍恢复为备份时的密码；发生安全事件时请重新生成有关教师密码。恢复工具会拒绝不完整数据库以及将当前数据库恢复到自身。

## Linux/macOS 开发与运行

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r backend/requirements.lock.txt
.venv/bin/python run.py init-db
.venv/bin/python run.py init-admin
.venv/bin/python run.py start
```

PNG 必须有中文字体：Linux 可安装 Noto CJK 或通过 `EDUPULSE_FONT` 指定 CJK TTF/TTC。Windows默认微软雅黑。随包 Windows wheels 只适用于Python3.12 x64，不适用于Linux/macOS或其他Python版本。

前端源码开发需要 Node.js 20+：

```bash
cd frontend
npm ci
npm run dev
# 另一个终端在项目根目录：.venv/bin/python run.py start
# Vite 默认5173，开发代理默认后端8000
npm run build
```

生产只运行Python服务，由它同源托管 `frontend/dist`；不启动Vite，不请求外部字体或CDN。

## 数据库创建与迁移

`python run.py init-db` 幂等创建schema v4和初始科目/年级/主校区字典，记录 `schema_versions`。模型定义见 `backend/app/db.py`。schema v1升级使用 `backend/app/migrations.py` 中的显式事务迁移，给学生和班级编号启用AUTOINCREMENT；随后schema v2→v3为教师/类别添加删除标记，把班级旧时段复制到每条学生报名关联的新student_weekly_slots表；v3→v4增加班级自动/手动命名标记，旧名称保守保留；保留已有编号、关联、评价和历史快照，并根据历史记录保留编号高水位。升级前自动用SQLite Backup API备份旧库到数据目录backups，升级后检查外键。请先停止旧服务并另行备份，再启动修复版。该迁移不会修复升级前已经出现的编号混用记录。后续schema变更仍需显式迁移，不能依靠create_all修改已有列。

本轮独立检查后的修复、schema v4升级和验证见 [缺陷修复说明](docs/BUG_FIXES_2026-10-15.md)。已有班级如需名称跟随档位，编辑时点击“恢复自动命名”并保存。
