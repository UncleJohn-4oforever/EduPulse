EduPulse 校区主机使用说明

一、第一次使用（只在作为服务器的校区主机上操作）
1. 安装 Python 3.12（64 位），安装时保留 Python Launcher 选项。
   如果收到的是含 Python 文件夹的完整分发包，可直接使用旁边的“安装Python.bat”。
   仅含 EduPulse 文件夹的代码包仍需自行准备 Python；首次使用都需要完成安装和账号设置。
2. 将压缩包完整解压到 D:\EduPulse 等可写目录，不要在压缩包里直接运行。
3. 双击“首次运行.bat”，按提示创建本校区教学主管账号和密码。
   密码至少14位，包含字母和数字；输入密码时屏幕不显示字符，属于正常现象。
4. 双击“开始.bat”，自动打开“校区登录入口”网页。
5. 点击醒目的“校区统一登录网址”进入系统，也可以复制网址发给老师或其他主管。
   主管和教师都使用同一个网址，输入各自账号密码后自动进入对应工作区。

二、以后每天使用
双击“开始.bat”即可。后台已运行时，不会重复启动。
关闭网页或启动窗口，不会结束后台。主机需要保持开机，不能休眠。
需要停止服务时，双击“结束后台.bat”；需要先关闭再打开时，双击“重启.bat”。
主机网络地址变化后，再次双击“开始.bat”即可获取并复制新网址。

三、老师及其他主管的电脑、手机
无需安装 Python 或本系统，只需要浏览器。
设备需连接校区同一网络，用主机分享的统一登录网址访问。
“主管备用网址”仅限主机本机使用，不要将这个地址发给其他设备。
如果同一网络仍不能访问，请检查 Windows 防火墙是否允许该主机的系统端口（默认8000）。

四、数据与账号
本包不包含原校区的教师账号、学生名单或数据库；各校区创建自己的账号和数据。
新安装自带科目和年级字典，校区名称可在主管端“设置”中修改。
数据默认保存在运行用户的 EduPulseData 文件夹中。请固定使用同一个 Windows 用户启动。
定期运行 backup.bat 备份数据；详细操作请查看 README.md。

本包面向 Windows 64 位校区主机；包含系统依赖的离线安装文件，首次使用不需要 Node.js。
